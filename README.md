# 局域网投递板

给家里多台设备使用的局域网文字、图片和文件共享板。无需登录，打开同一个地址即可互相投递内容。

## 启动

需要 Node.js 20.19 或更高版本：

```bash
npm install
npm run dev
```

服务会监听 `0.0.0.0`。在运行这台机器上查看终端打印的局域网地址，例如 `http://192.168.1.20:3000`，然后让手机、平板或其他电脑在同一 Wi-Fi 下打开它。

支持：

- 多条文字内容，`Ctrl/Cmd + Enter` 快速发送
- 批量上传图片和文件，单个文件最大 12 MB
- 文字一键复制，图片和文件一键下载
- 所有设备自动刷新共享板，最多保留最近 80 条内容

当前内容仅保存在服务进程的运行内存中，重启服务后会清空；这也意味着它不会把家庭文件永久写入磁盘。
