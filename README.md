# 我家的共享桌面

一个只在家中局域网使用的轻量共享板，用来在电脑、手机、平板和安卓设备之间传递文字、图片和文件。无需登录，也不依赖 iCloud。

## 启动

需要 Node.js 20.19 或更高版本：

```bash
npm install
npm run dev
```

服务会监听 `0.0.0.0:3000`。在同一 Wi-Fi 下打开终端显示的地址，例如：

```text
http://192.168.1.20:3000
```

也可以通过局域网 mDNS 使用类似 `http://share.local:3000` 的地址；如果把服务配置到 80 端口，则可以省略端口号。

## 功能

- `Enter` 发送文字，`Shift + Enter` 或 `Alt + Enter` 换行
- 文字卡片点击即复制，并显示“已复制”提示
- 图片和文件可选择上传，也可以直接拖到输入框自动上传
- 图片保持原比例，点击图片可预览，文件和图片都可以下载
- 桌面端文字与图片/文件分列显示；手机端自动变成按时间倒序的单列混排
- 支持清空全部共享内容
- 单个文件最大 12 MB，最多保留最近 80 条内容
- 已配置 iPad 主屏幕图标和 Web App manifest

## 数据与隐私

文字、图片和文件只保存在当前 Node 服务进程的内存中：

- 不写入磁盘
- 不上传 Git 或 GitHub
- 不上传第三方云服务
- 重启服务后自动清空

`.gitignore` 额外忽略了 `/uploads/`、`/data/` 和 `/.runtime/`，即使未来增加本地持久化，也不会误把用户内容提交到 Git。
